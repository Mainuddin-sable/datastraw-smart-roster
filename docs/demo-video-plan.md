# 3–5 Minute Assessment Demo Plan

Target length: about 4 minutes. Use a prepared demo organization and avoid showing secrets or personal data.

1. **0:00–0:35 — Setup and structure:** Show the organization, Pods, brands, processes, employee count, and Pod Lead selectors. Mention the API and database-backed model.
2. **0:35–1:15 — Scheduling inputs:** Show a process calendar, holiday behavior, staffing minimum, and an employee weekly-off/approved leave rule in Swagger. Explain the effective dates.
3. **1:15–2:15 — Roster generation and views:** Generate a month; show the company-wide schedule and filter to Pod, brand, process, and employee.
4. **2:15–3:15 — Conflict handling:** Change an employee’s availability or approve a time-off request, independently revalidate, and show the coverage conflict and any valid replacement candidates.
5. **3:15–4:00 — Planner control and close:** Edit or lock an assignment, revalidate it, briefly show the test results/README answers, then state known limitations such as no public deployment and no comp-off balance accounting.

Before recording, assign the intended lead for each Pod, use a separate assessment-compliant demo database, and verify the local frontend and API against that same database. A public deployment has not been verified; do not present a mocked test as a live integration demonstration.
